## 二、分支与提交规范

- 分支模型：`main`（Protected，禁止直接 push）／ `dev`（集成分支）／ `feature/<功能名>`（个人开发分支）
- 提交信息前缀：`feat:` 新增功能　`fix:` 修复缺陷　`docs:` 文档变更
- 合并流程：`feature/*` → 发起 Pull Request → 至少 1 人 Review → 合并入 `main`
- 每天至少 push 一次，不把代码攒到截止日前一天
- 不上传编译产物与密钥，统一由 `.gitignore` 拦截
